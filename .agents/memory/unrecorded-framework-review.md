---
name: Owner review of unrecorded framework access
description: Approval boundary for roles lacking saved framework decisions.
---

Existing unrecorded framework roles require case-by-case Owner review. The Owner
chose to manually right-click members and assign appropriate roles, not to
authorize blanket adoption or invented historical approvals.

**Why:** A later matching native choice cannot establish who assigned an older
access role, and manual Discord assignment is not a saved bot approval.

**How to apply:** Preserve existing roles, human-reviewed extras and all protected
accounts. Request explicit per-member primary/extra decisions before recording
reconciliation, using the actual new review time rather than backdating.
