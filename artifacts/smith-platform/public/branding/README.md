# Agent Smith branding
Standalone Smith artwork was not available. Placeholders are used until you upload:
- `agent-smith-avatar.png` (square, 512x512 or larger)
- `agent-smith-banner.png` (wide, about 1200x320)
Place them in this folder (`artifacts/smith-platform/public/branding/`). The UI uses a supplied PNG when present and falls back once to the SVG placeholder if loading fails. Without a PNG it uses the clearly labeled placeholder directly. The Hallowed Core crest is not Smith artwork; do not substitute it.
